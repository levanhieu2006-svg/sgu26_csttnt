Tiền xử lý dữ liệu¶

Biến đổi ảnh về miền trị [0,1], mở rộng chiều (expand_dims) và chuyển nhãn (labels) sang dạng one-hot vector.

In [3]:
# Biến đổi ảnh về miền trị [0,1]
x_train_f = x_train_f.astype("float32") / 255
x_test_f = x_test_f.astype("float32") / 255

# Mở rộng shape tại chiều cuối cùng: (n, 28, 28) --> (n, 28, 28, 1)
x_train_f = np.expand_dims(x_train_f, -1)
x_test_f = np.expand_dims(x_test_f, -1)

# Chuyển đổi y_train, y_test sang dạng one-hot
num_classes = 10
y_train_f_hot = keras.utils.to_categorical(y_train_f, num_classes)
y_test_f_hot = keras.utils.to_categorical(y_test_f, num_classes)

print("x_train_f shape:", x_train_f.shape)
print(x_train_f.shape[0], "train samples")
print(x_test_f.shape[0], "test samples")

Xây dựng và Huấn luyện Model¶

Sử dụng kiến trúc mạng Convolutional Neural Network (CNN) tương tự như bài 1 để rút trích đặc trưng và phân loại.

In [4]:
# Xóa các lưu trữ
keras.backend.clear_session() 

# Xây dựng model
input_shape = (28, 28, 1)
input_ = keras.Input(shape=input_shape)

# block 1
x = keras.layers.Conv2D(32, kernel_size=(3, 3), activation="relu")(input_)
x = keras.layers.MaxPooling2D(pool_size=(2, 2))(x)

# block 2
x = keras.layers.Conv2D(64, kernel_size=(3, 3), activation="relu")(x)
x = keras.layers.MaxPooling2D(pool_size=(2, 2))(x)

# classification layers
x = keras.layers.Flatten()(x) 
x = keras.layers.Dropout(0.5)(x) 
output_ = keras.layers.Dense(num_classes, activation="softmax")(x) 

model_fashion = keras.Model(inputs=input_, outputs=output_) 
model_fashion.summary()
